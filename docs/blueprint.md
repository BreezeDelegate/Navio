# **App Name**: ModularAI Forge

## Core Features:

- Prompt-based Bot Specification Input: Allow users to describe the desired 'muse&call' bot functionality using natural language prompts.
- AI-driven Bot Specification Generation: Utilize a generative AI 'prompt engine' tool to interpret user input and generate a detailed bot specification based on the requested 'muse&call' capabilities and context.
- 44-36 Standard Adherence Guidance: Provide AI-powered guidance and validation to ensure the generated bot specifications comply with the '44-36' structural standard for new AI-built modules.
- AI Module Interaction Definition: Enable users to define how the newly specified bot integrates with and interacts with other AI-built modules.
- Generated Specification Display: Present the generated bot specification in a clear, structured, and easy-to-understand format.
- Specification Management: Offer basic functionalities to save and load generated bot specifications for future use or modification.

## Style Guidelines:

- The application employs a dark color scheme, reflecting a professional and tech-forward aesthetic suitable for AI development. The primary color is a rich, deep violet (#A322C9), offering a sophisticated anchor for interactive elements and highlights. The background is a very subtle, dark grey with a hint of the primary violet (#1C181D), providing a calm and focused environment. A vibrant medium-purple blue (#7A62FF) serves as the accent color, strategically used for call-to-action elements and visual emphasis, ensuring excellent contrast.
- Headlines and prominent text use 'Space Grotesk' (sans-serif), lending a modern, tech-infused character. Body text and longer descriptions utilize 'Inter' (sans-serif), chosen for its readability, clarity, and clean aesthetic, maintaining a professional yet accessible tone.
- Use sleek, minimalist line icons that align with a digital and abstract AI theme, representing concepts like 'generate', 'module', 'bot', and 'connect'.
- Implement a clean, organized two-column layout: a left-sidebar for navigation and main settings, and a larger right pane for prompt input, AI generation results, and detailed configuration. Focus on generous spacing and a grid-based approach for easy content consumption and interaction.
- Incorporate subtle, fluid transitions and micro-interactions for input fields, button presses, and when displaying generated content. A simple loading animation (e.g., a pulsating element) will indicate when the AI is processing.
